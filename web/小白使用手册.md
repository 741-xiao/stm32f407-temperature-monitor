# 温湿度上位机使用手册

本版仅显示 SHT30 温湿度数据。开发者：**肖肃**，学号：**202440700102**。

1. 启动 MySQL，确保存在 `mytest` 数据库。默认账号为 `root`；运行前在 PowerShell 设置 `$env:DB_PASSWORD = "你的数据库密码"`。
2. 双击项目根目录的 **启动温湿度上位机.cmd**，或在根目录执行：
   `java "-Dfile.encoding=UTF-8" -jar "web/huiningLi/WebServer/target/WebServer-sht30.jar"`

   请先进入本项目根目录 `5 TFTLCD显示`，或使用该 JAR 的实际完整路径。
3. 浏览器打开 **http://localhost:8080/**。
4. 给开发板上电并等待 WiFi 联网，按按键1开始采集；网页每 2 秒自动刷新。
5. 按按键2停止采集。其它功能键在 LCD 和串口提示“按键错误”。

列表为中文，包含温度、湿度、报警阈值、采集时报警状态、设备 IP 和接收时间，页面显示开发者信息。保留最近 1000 条的网页展示，可搜索、导出 CSV、查看温湿度曲线；数据库中的较早记录仍然保留。

报警由开发板自动执行，高于阈值开启，低于阈值关闭，停止采集关闭。网页显示历史采集时的状态，不提供手动蜂鸣器开关。

数据库密码不同时，在 PowerShell 中设置 `$env:DB_PASSWORD = "你的密码"` 后运行 JAR。程序自动创建 `sht30_samples` 表，不需要导入旧 `coll_data.sql`。

修改源码后，在项目根目录执行 `mvn -f web/huiningLi/pom.xml verify`，再重启 `WebServer-sht30.jar`。不要运行旧的 dashboard / xiaosu JAR。

完整接线、WiFi 配置、编译烧录、串口编码和验收步骤，请查看根目录 [使用说明](../使用说明.md)。
